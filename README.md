# قالب عروض الأسعار | BANNAY

صفحة ثابتة لإنشاء عروض أسعار باسم **Bannay Solutions Establishment**.

- افتح الصفحة، املأ البيانات، ثم اختر **تصدير PDF** واحفظ الملف من نافذة الطباعة.
- تحفظ المسودة في المتصفح على الجهاز نفسه؛ لا توجد مزامنة بين الأجهزة ولا إرسال لبيانات العملاء إلى خادم.
- تتضمن الصفحة بيانات التحويل وملاحظة ضريبية وفق الحالة التي قدمها مالك المؤسسة عند إعداد القالب. يجب تحديثها إذا تغيرت البيانات أو حالة التسجيل.
- ملف الخط Noto Sans Arabic مرفق بترخيصه OFL داخل `assets/fonts/`. شعار BANNAY من الهوية البصرية الخاصة بالمؤسسة.
